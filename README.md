# MySQL Master with GTID Replication Setup

Этот проект содержит Ansible playbook для настройки MySQL с использованием Percona Server на сервере мастере с включенной GTID репликацией. Playbook также импортирует дамп базы данных `bet.dmp` и создает пользователя для репликации.

## Описание Playbook

### Основные функции

- Установка Percona Server
- Настройка GTID репликации
- Создание пользователя для репликации
- Импорт базы данных из дампа

### Переменные

- `mysql_root_password`: Пароль для пользователя root MySQL.
- `replication_user`: Имя пользователя для репликации.
- `replication_password`: Пароль для пользователя репликации.
- `percona_repo_url`: URL-адрес репозитория Percona для установки.
- `dump_file`: Путь к файлу дампа базы данных, который будет импортирован.

### Пример использования

1. Убедитесь, что у вас установлен Ansible.
2. Настройте файл инвентаризации Ansible, добавив сервер мастера в группу `mysql_master`.
3. Измените переменные в playbook, чтобы указать правильный путь к дампу базы данных и необходимые пароли.
4. Запустите playbook с помощью следующей команды:

   ```bash
   ansible-playbook -i inventory_file setup_mysql_master.yml
   ```


# MySQL Slave Setup with GTID Replication

Этот проект содержит Ansible playbook для настройки MySQL на сервере слейве с использованием Percona Server и включенной GTID репликацией. Playbook выполняет необходимые шаги для установки MySQL, изменения пароля пользователя root, а также настройки параметров репликации с мастером.

## Описание Playbook

### Основные функции

- Установка Percona Server
- Настройка GTID репликации
- Изменение пароля для пользователя root
- Настройка соединения со мастером для репликации

### Переменные

- `mysql_root_password`: Пароль для пользователя root MySQL.
- `master_host`: IP-адрес или доменное имя сервера мастера.
- `replication_user`: Имя пользователя для репликации.
- `replication_password`: Пароль для пользователя репликации.

### Пример использования

1. Убедитесь, что у вас установлен Ansible.
2. Настройте файл инвентаризации Ansible, добавив сервер слейва в группу `mysql_slave`.
3. Измените переменные в playbook, чтобы указать правильный IP-адрес мастера и необходимые пароли.
4. Запустите playbook с помощью следующей команды:

   ```bash
   ansible-playbook -i inventory_file setup_mysql_slave.yml
   ```
